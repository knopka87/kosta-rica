# Этап 11: Обратный путь 🏠

**Даты:** 7–9 ноября  
**Маршрут:** Панама → Стамбул → Москва

---

## 📍 Обзор

Долгий обратный путь через Стамбул. 2 пересадки, ~24 часа в дороге. Главное — комфортно добраться домой.

---

## ⏰ Тайминг

| Время | Активность |
|-------|------------|
| Утро 7 ноября | Регистрация на рейс в Панаме |
| День 7 | Вылет Панама→Стамбул (~15–18ч полёта) |
| Ночь 7/8 | Пересадка в Стамбуле |
| Утро 8 | Вылет Стамбул→Москва (~10ч полёта) |
| День 8–9 | Прилёт в Москву, конец путешествия |

---

## ✅ Что делать

### Утро/День 7 ноября
- [ ] Check-out из отеля
- [ ] Трансфер в аэропорт Панама-Сити
- [ ] Регистрация на рейс (за 3 часа!)
- [ ] Прохождение пограничного контроля
- [ ] Обед в аэропорту
- [ ] Поиск gate, отдых перед долгим перелётом

### Полёт Панама→Стамбул
- [ ] Лёгкий обед/ужин (обычно включён в билет)
- [ ] Сон (используйте наушники, маску для глаз)
- [ ] Прогулка по салону (каждые 3–4 часа)
- [ ] Гидратация: пейте больше воды
- [ ] Развлечения: фильмы, музыка, книги

### Пересадка в Стамбуле
- [ ] Прохождение погранконтроля (если нужно)
- [ ] Поиск ресторана/перекус
- [ ] Если долгая пересадка: рассмотрите options для отдыха
- [ ] Поиск следующего gate
- [ ] Проверить время вылета!

### Полёт Стамбул→Москва
- [ ] Сон
- [ ] Лёгкий перекус (если не был включён)
- [ ] Развлечения
- [ ] Подготовка к прилёту (документы)

### Прилёт в Москву
- [ ] Прохождение пограничного контроля
- [ ] Получение багажа
- [ ] Трансфер в город
- [ ] **Добро пожаловать домой!** 🏠

---

## 📋 Багаж и документы

### Что проверить
- [ ] Паспорт (срок действия > 6 месяцев)
- [ ] Виза (если нужна для России)
- [ ] Путевая страховка (действующая до конца поездки)
- [ ] Копии всех документов в телефоне
- [ ] Карта с деньгами (на случай если багаж задержат)
- [ ] Наличные USD/EUR (на всякий случай)

### Ручная кладь
- [ ] Документы (паспорт, билеты, страховка)
- [ ] Сменная одежда на 2 дня
- [ ] toiletries (зубная щётка, паста, увлажняющий крем)
- [ ] Аптечка базовая
- [ ] Зарядки, powerbank
- [ ] Вода (пройти через контроль)
- [ ] Перекус (батончики, орехи)
- [ ] Наушники
- [ ] Маска для глаз
- [ ] Подушка для шеи (если используете)

## ⚠️ Важно

- **Время:** закладывайте запас на дорогу в аэропорт! Задержки на дорогах — частое явление
- **Багаж:** убедитесь, что багаж проверяется до конечного пункта (Москва)
- **Документы:** все документы должны быть в порядке
- **Здоровье:** долгий перелёт — нагрузка на организм. Пейте воду, двигайтесь
- **Роуминг:** убедитесь, что мобильный интернет работает до прилёта
- **Timezone:** разница с Москвой в Панаме ~13 часов (в Москве позже)

---

## 💡 Советы

- **Сон:** начните спать по расписанию Москвы ещё в КР, чтобы минимизировать джетлаг
- **Гидратация:** в самолёте сухо, пейте воду, используйте увлажняющий крем
- **Одежда:** в самолёте холодно, возьмите тёплый слой
- **Развлечения:** скачайте фильмы/музыка заранее, не надейтесь на Wi-Fi
- **Стамбул:** если пересадка >6 часов, посмотрите options для отдыха (спальни в аэропорту, краткая экскурсия)
- **По прилёте:** первый день — отдых, не планируйте дела
