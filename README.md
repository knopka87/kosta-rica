# Коста-Рика 2026 — личный путеводитель

Статический сайт-помощник по поездке **30.10 – 10.11.2026**: Киров → Москва → Стамбул → Панама → Коста-Рика → обратно.

Открывается как обычные HTML-файлы, деплоится на **GitHub Pages** без сборки на сервере.

## Страницы

| Страница | Что внутри | Источник |
|---|---|---|
| `index.html` | Обзор, обратный отсчёт, **карточка текущего этапа**, ключевые даты | `src/index.html` |
| `steps.html` | **Оглавление маршрута: 9 шагов** + какой этап сейчас | `build.py` (STEPS) |
| `step-prep.html` … `step-home.html` | **Шаги маршрута** — отдельная страница на каждый этап (см. ниже) | `build.py` (STEP_INCLUDES) |
| `hotel.html` | Отель, **карта отеля и окрестностей**, что рядом, транспорт | `src/hotel.html` |
| `phrasebook.html` | Испанский разговорник: фразы, произношение, числа, экстренные номера | `src/phrasebook.html` |
| `budget.html` | План бюджета + **мульивалютный трекер трат** (₽/$/₡, балансы, CSV) | `src/budget.html` |
| `journal.html` | **Дневник поездки**: записи офлайн, правка, экспорт в .md | `src/journal.html` |
| `dokumenty.html` | **PDF за паролем** (реальное шифрование) | `docs/*.bin` |
| `credits.html` | Атрибуция фото и источники | — |

Архивные страницы-«монолиты» (`marshrut`, `eda`, `sbory`, `pokupki`, `pravila`,
`lifehacks`, `dela`) по-прежнему собираются и доступны по прямой ссылке, но **выключены
из навигации**: их контент перенесён внутрь шагов маршрута.

## Пошаговый маршрут

Маршрут разбит на **подготовку + 9 этапов**, каждый — отдельная страница
(`step-*.html`), собранная `build.py` из markdown-источников:

| Шаг | Страница | Этап |
|---|---|---|
| 0 | `step-prep.html` | Подготовка: билеты, сборы, дела, еда в поезд, деньги, связь, аптечка |
| 1 | `step-train-msk.html` | Поезд Киров → Москва (30.10) |
| 2 | `step-ist-panama.html` | Москва → Стамбул → Панама (31.10) |
| 3 | `step-panama-night.html` | Ночь в Панаме (31.10 – 01.11) |
| 4 | `step-arrival-cr.html` | Прилёт в Коста-Рику, SJO → LIR → Тамариндо (01.11) |
| 5 | `step-tamarindo.html` | Тамариндо: 5 дней (01–06.11) |
| 6 | `step-sjo-window.html` | Вылет и окно в SJO (06.11) |
| 7 | `step-panama-days.html` | Панама: полные сутки (06–07.11) |
| 8 | `step-home.html` | Обратно: Панама → Москва → Киров (07–09.11) |

- **Текущий этап определяется по дате** в браузере (`assets/js/steps.js`):
  на главной — карточка «Сейчас», в оглавлении — подсветка и первая карточка,
  на страницах шагов — баннер «Вы здесь / Сейчас идёт другой шаг».
  Метаданные этапов (даты, `after`/`until` время, иконки, описания) лежат в
  сиде `#steps-seed`, встроенном в `index.html`, `steps.html` и каждый `step-*.html`.
- Секции шагов собираются из markdown по явной карте `STEP_INCLUDES` в `build.py` —
  правки контента в `../kosta-rica/*.md` подхватываются при пересборке.
- Навигация по шагам: prev/next внизу страницы, оглавление `steps.html`,
  пункт меню «Маршрут»; на каждом шаге меню подсвечивает «Маршрут».

## Сборка

Нужен [pandoc](https://pandoc.org/).

```bash
python3 build.py
```

Скрипт берёт markdown из `../kosta-rica/`, HTML-страницы из `src/`, оборачивает их в `template.html` и кладёт готовые `*.html` в корень. Ссылки вида `eda.md` автоматически превращаются в `eda.html`.

После правки любой заметки в `../kosta-rica/` — пересобрать.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```

(Для проверки страницы «Документы» нужен именно сервер, а не `file://` — браузеру нужен `fetch`.)

## Офлайн (PWA)

`build.py` генерирует `sw.js` — service worker кэширует все страницы, стили, скрипты,
фото и зашифрованные документы, поэтому сайт полностью работает без интернета
(раздел «Документы» и парольные фрагменты — тоже). Версия кэша = хэш содержимого:
после любой пересборки (в том числе регенерации `docs/` шифрованием) запускай
`python3 build.py` — старый кэш удалится сам. `manifest.json` делает сайт
устанавливаемым на домашний экран («Добавить на главный экран»).

В Android-приложении (Capacitor) service worker не используется — контент вшит в APK.

## Редактируемые списки

Чек-листы на страницах **«Сборы»** и **«Дела»** редактируются прямо в браузере
(`assets/js/editable-list.js`): отметки, добавление/удаление пунктов и разделов,
переименование, перестановка, экспорт/импорт JSON. Отметки живут в `localStorage`
(`cr:list:v1:sbory`, `cr:list:v1:dela`) и переживают офлайн-перезагрузки.

- База списка — в HTML (стабильные `data-id`/`data-section` расставляет `build.py`),
  поверх — оверлей правок в localStorage; «Вернуть исходный список» сбрасывает оверлей.
- Сводка на главной рендерится из seed-JSON, встроенного в `index.html` при сборке,
  и читает тот же ключ `cr:list:v1:dela` — отметки общие со страницей «Дела».
- Старые отметки (`cr:checks:sbory`, `cr:checks:index`) мигрируют автоматически.

## Погода и календарь

- **Погода** (`assets/js/weather.js`, виджеты на главной и «Отель»): Open-Meteo
  network-first — сначала отдаётся кэш из `localStorage` (`cr:weather:tamarindo`),
  затем прогноз обновляется из сети. Без сети и без кэша — встроенные климатические
  нормы ноября для Тамариндо. Внешний API минует service worker (sw пропускает
  чужие домены), поэтому кэш живёт именно в localStorage.
- **Календарь** (`calendar.ics`, генерируется `build.py`): 16 событий маршрута —
  поезда, рейсы, отели — в UTC без VTIMEZONE, принимается Apple/Google/Outlook.
  Кнопка «Скачать календарь» — на главной и в «Маршруте»; файл прекэширован
  для офлайна.

## Разговорник, бюджет и журнал

- **Разговорник** (`src/phrasebook.html`) — статичная страница без JS: испанские
  фразы с фонетическим произношением по категориям (ресторан, такси, отель,
  аптека, экстренные), числа и время, нюанс Панамы (бальбоа = монеты, ходят $).
- **Бюджет** (`budget.html` + `assets/js/budget.js`) — план по категориям
  (билеты ≈ 375 331 ₽, еда $250–400, покупки $165–370) и **мульивалютный
  трекер трат**: валюта на каждой записи (₽ рубли / $ доллары / ₡ колоны),
  баланс по каждой валюте и остаток = баланс − траты, итоги с чипами категорий
  (суммы по валютам), удаление, выгрузка CSV с колонкой валюты.
  Состояние — `localStorage cr:budget:v2`; старые записи `cr:budget:v1`
  мигрируют автоматически в доллары.
- **Журнал** (`journal.html` + `assets/js/journal.js`) — дневник поездки:
  записи с датой и заголовком, правка (✎) и удаление (✕), сортировка по дате
  (новые сверху), экспорт всего журнала в Markdown. Состояние —
  `localStorage cr:journal:v1`, синхронизации нет: экспорт .md после поездки.

## Офлайн-карта

- На странице «Отель» — интерактивная карта OpenStreetMap, которая работает
  **полностью без интернета**: векторные тайлы (Protomaps-схема, z0–13,
  Гуанакасте + центральная Коста-Рика + Панама) лежат одним файлом
  `assets/map/central-america.pmtiles` (~41 МБ) и прекэшируются service worker'ом.
- Стек: Leaflet 1.9.4 + protomaps-leaflet 5.1 (вендор в `assets/vendor/`),
  лениво грузятся только на страницах с mount `[data-map]` (см. `assets/js/maps.js`).
- SW отдаёт PMTiles-запросы с `Range` нарезкой из кэша (`pmtilesRange` в `sw.js`),
  поэтому reader'у не нужна сеть.
- Перегенерация тайлов: `protomaps/basemaps` (`tiles/`, Maven) +
  `--osm-path=<geofabrik extract> --maxzoom=13 --bounds=<route bbox>`.

## Документы: шифрование

PDF из `../kosta-rica/documents/` и секретные HTML-фрагменты шифруются в `docs/`.
Секретные участки в markdown-источниках обозначены маркерами `<!-- secret -->` … `<!-- /secret -->`:
`build.py` вырезает их в plaintext-фрагменты `.tmp-secret/` (каталог в `.gitignore`,
в собираемый сайт и в git он не попадает), а в публичную страницу ставит заглушку с паролем.

```bash
python3 build.py   # сайт + .tmp-secret/
DOCS_PASSWORD=... go run ./tools/encryptdocs -in ../kosta-rica/documents -extra .tmp-secret -out docs
```

- Алгоритм: **AES-256-GCM**, ключ — **PBKDF2-HMAC-SHA256, 210 000 итераций**, salt 16 байт на файл.
- `docs/manifest.bin` — список файлов, сам зашифрован (имена билетов не светятся в открытом виде).
- Пароль проверяется расшифровкой `docs/manifest.bin`; отдельного быстрого verifier нет.
- PDF из `-in` шифруются как `doc-NN.bin`; файлы из `-extra` — как `<имя>.bin`
  (стабильные ссылки из HTML-заглушек, например `secret-marshrut.html.bin`).
- Расшифровка — в браузере (`assets/js/docs.js`, WebCrypto): PDF открываются в новой вкладке,
  HTML-фрагменты вставляются прямо на странице (слот `.secret-slot`).
- Пароль один на всё и живёт в `sessionStorage` (в рамках открытой вкладки).

Сменить пароль = перегенерировать `docs/` с новым `DOCS_PASSWORD` и обновить пароль в заметках.

> **Честная оговорка:** на статическом хостинге пароль физически находится в JS и его можно подобрать перебором. Защита реальная (без пароля PDF не читаются ни по какой ссылке), но это не замена серверной авторизации — это барьер от любопытных и от случайного доступа к ссылке.

## Деплой на GitHub Pages

1. Залить папку `kosta-rica-site` как репозиторий (или как `/docs` существующего репо).
2. Settings → Pages → Source: `main` / папка `/` (или `/docs`).
3. Сборка не нужна — все HTML уже в репозитории.

Ссылки относительные, поэтому проектные Pages (`username.github.io/repo/`) работают как есть.

## Структура

```
kosta-rica-site/
├── index.html, steps.html,        # собранные страницы (коммитятся)
├── step-*.html, marshrut.html, …  # шаги маршрута + архивные монолиты
├── template.html                  # общий каркас (шапка, меню, футер)
├── build.py                       # markdown → HTML + генерация sw.js
├── sw.js, manifest.json           # офлайн-кэш и PWA-манифест (генерируются)
├── src/                           # HTML-контент страниц, которые собираются вручную
├── assets/
│   ├── css/style.css
│   ├── js/main.js                 # меню, чек-листы, обратный отсчёт, service worker
│   ├── js/docs.js                 # пароль + расшифровка PDF и секретных фрагментов
│   ├── js/editable-list.js        # движок редактируемых чек-листов
│   ├── js/weather.js, maps.js     # погода и офлайн-карта
│   ├── js/steps.js                # текущий этап маршрута по дате
│   ├── js/budget.js, journal.js   # трекер трат и дневник поездки
│   ├── map/central-america.pmtiles  # офлайн-тайлы (~41 МБ)
│   ├── vendor/                    # Leaflet + protomaps-leaflet
│   └── img/                       # фото (Wikimedia, CC) + SVG-схемы
├── docs/                          # зашифрованные PDF и фрагменты + манифест
└── tools/encryptdocs/             # Go-утилита шифрования
```
